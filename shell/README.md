# Practical: UNIX/Linux

## Aims

* Familiarising yourself with UNIX/Linux concepts and commands
* Accessing Linux at Durham

## Background

There are three main ways of accessing Linux in university computer labs



1. Some of the CIS PCs allow dual booting i.e. running Linux directly on the machine from boot-up. Access to this will depend on the lab you are in.

2. Use the git bash shell. We will take about this more in later practicals

3. Use the putty application on Windows with get secure shell (ssh) access to NCC, the departmental Linux timeshare machine.  This will give you terminal access, and can be used from any internet connection in the world, provided you use the university VPN. putty and/or ssh is very commonly available so this is how I usually access remote machines.

If you are using your own machine you can either install putty (for Windows) to access NCC, or run the Terminal application under OSX to get access to BSD (UNIX derivative) directly on the machine.

## Tasks

1. Try as many different ways as you can for accessing Linux/UNIX/BSD.

2. Then choose one of them and complete the UNIX tutorial at <http://swcarpentry.github.io/shell-novice/>
